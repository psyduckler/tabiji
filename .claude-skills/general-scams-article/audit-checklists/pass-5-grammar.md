# Pass 5 · Grammar & Spelling

## Spelling

- [ ] Run a spell-check across the rendered HTML body text
- [ ] Place names verified (Sihanoukville, Myawaddy, Bokeo, Shwe Kokko, etc.)
- [ ] Person names verified (Erin West, etc.)
- [ ] Brand names verified (WhatsApp not "Whatsapp", LinkedIn not "Linkedin", JPMorgan not "JP Morgan")
- [ ] Subreddit names verified against actual Reddit casing (r/CryptoScams not r/cryptoscams)
- [ ] Diacritics correct on non-Latin terms (shā zhū pán, An Garda Síochána, Café, etc.)
- [ ] Chinese characters validated against Wikipedia (杀猪盘, etc.)

## Grammar

- [ ] Subject-verb agreement throughout
- [ ] Compound modifiers hyphenated when prenominal ("crypto-investment fraud" — yes; "fraud is crypto-investment" — no)
- [ ] No missing prepositions in verb constructions ("rebranded as ETRDStocks" not "rebranded ETRDStocks")
- [ ] Comma splices flagged
- [ ] Tense consistency within paragraphs (story paragraphs in past tense or present tense, not mixed)
- [ ] Pronoun antecedent clarity (no orphan "they" / "this" / "it")

## Homophones

- [ ] Its / it's correctly distinguished
- [ ] Affect / effect correctly distinguished
- [ ] Their / there / they're correctly distinguished
- [ ] Your / you're correctly distinguished
- [ ] Then / than correctly distinguished
- [ ] Loose / lose correctly distinguished

## Punctuation

- [ ] Em-dashes (—) used correctly for sentence-level breaks
- [ ] En-dashes (–) used for ranges only ($15K–$500K, 24–48h, 2025–2026)
- [ ] Hyphens (-) used for compounds only
- [ ] Quotes are typographic (curly) only when generated by HTML autocorrect; otherwise use straight (")
- [ ] Periods at the end of every list item OR no list items have periods (consistent within a list)
- [ ] Oxford comma used consistently within paragraphs

## Capitalization

- [ ] Proper nouns capitalized (FBI, OFAC, Adult Protective Services, U.S. Institute of Peace)
- [ ] Mid-sentence capitals for org acronyms (NAPSA, RCMP, ACCC)
- [ ] Title-case in section headings and FAQ questions
- [ ] No sentence-case inconsistencies in similarly-structured headings

## Number formatting

- [ ] Currencies always in USD format with $ ($5.8B, $15,000) unless quoting a non-US source
- [ ] Large numbers use either commas ($15,000) or B/M/K abbreviations ($5.8B), not both
- [ ] Percentages always with % sign (10%) not "ten percent"
- [ ] Decimals consistent (1.5/100w, not 1,5/100w)
