# Scam Atlas Builder

Build one complete `/scams/atlas/<slug>/` page from `entries.json` taxonomy through full HTML, hero comic, and shippable artifact. Editorial-only approach — no per-scam recategorization required.

## When to use

- User asks to "build atlas page for <slug>" or "ship atlas <name>"
- Producing one of the ~64 atlas entries listed in `generators/scam-atlas/data/entries.json`
- **Not for** rewriting an existing atlas page (different workflow), and **not for** city scam pages (use `scam-page-builder`)

## Required input

- The atlas-entry **slug** (matches `entries.json` exactly, e.g., `taxi-meter-manipulation`, `the-gold-ring-trick`)
- Confirm the slug exists in `generators/scam-atlas/data/entries.json` before starting

## Pipeline landscape (read these first)

| Source | Purpose |
|---|---|
| `generators/scam-atlas/data/entries.json` | Canonical atlas taxonomy. 64 entries with slug, name, entryStyle (broad/specific), synonyms, parentEntry, primaryBookFunnels, primaryQueryTarget. **Always start here.** |
| `generators/scam-atlas/data/synonyms.json` | Tag/category lookup map. Used by extract.py only. Atlas pages don't read this directly. |
| `generators/scam-atlas/output/auto-assigned.json` | Output of extract.py — 1,971 scams pre-assigned to atlas entries via synonym matching. **Use for country-count signal in the geographic table.** |
| `generators/scam-atlas/output/entry-inventory.json` | Per-entry stats: count, countryCount, countries[], cities[], meetsThreshold. Use to pick case-study cities and validate ≥10 scams ≥4 countries before generating. |
| `/api/v1/scams/<city>.json` | Source data for case-study evidence (scam title, location, description). Read directly when writing a case-study scene. |
| `/scams/<city>/index.html` | Source for the per-city comic URL. Grep for `scam-comic.*<city>` to find the right scam-N number for the topic. |
| `assets/scams.css` | Shared CSS. Atlas pages use this *plus* significant inline overrides. **Critical: line ~1687 has `body.editorial-v2 .content { display: grid; ... }` — atlas pages MUST override this.** |
| `_includes/nav-main.html`, `_includes/footer-default.html` | Shared partials. Already have the "📋 Scam Atlas" entry in the Explore dropdown after [PR-TBD]. |
| `scripts/comic-pipeline/` | v2 comic generator (synthesize.py + generate.py + styles.py + cast.py). |
| `docs/comic-pipeline/styles/_default.md` | The locked default style block (warm watercolor storybook, country-agnostic). |

## The 19-section page anatomy (optimal order, learned from V0 iteration)

Built into `/scams/atlas/<slug>/index.html` in this exact order:

1. **`<head>`** — meta + JSON-LD + inline `<style>` overrides + shared-head include
2. **Nav** — shared partial (managed-include)
3. **Breadcrumb** — `Home › Scams › Atlas › <Name>` (current name in `<strong class="breadcrumb-current">`)
4. **`<main>` opens**
5. **`.atlas-hero`** — full-width indigo hero with `<h1>` (serif italic emphasis on a tabiji-voice phrase like "country by country") + `.hero-deck` (4 short fragments: "One scam family. Five sub-variants. Sixty-five countries.") + `.hero-stats` strip (4 cells)
6. **`<div class="content body-prose">` opens**
7. **Byline** — `<div class="page-byline">` with Bernard's photo + "Editor, tabiji.ai · Published [date]"
8. **Hero comic** — `<img class="scam-comic" src="https://img.tabiji.ai/scams/atlas/<slug>/hero.jpg">` (generated by comic-pipeline v2 — see below)
9. **`<p class="answer-first">`** — bold lead sentence (AEO-quotable, ≤22 words), then 4-5 short fragment sentences listing the 5 sub-variants, ending with the universal defense
10. **`.atlas-meta-rail`** — 6-cell grid: Category, Severity, Frequency, Typical loss, Top region, Reading time
11. **`.cross-links`** — 3 pills: "📋 Browse the full Atlas", "📍 By city", "📖 Travel Safety Books"
12. **`.atlas-toc`** with `.atlas-share-btn`** — sticky-on-desktop horizontal nav bar
13. **`.lead-scene`** — terracotta-bordered card with the strongest single case study, opening "A scene · <City> · <Time>" eyebrow + serif h2 + the case-comic image + 2-3 narrative paragraphs that close with: "That is N sub-variants in one ride. The rest of this page is what just happened to you, why it works, and the exact phrases that shut it down."
14. **`.takeaways-box`** with `.takeaways-icons`** — 5 bullets each with an inline `🌍/🇮🇹/📱/💡/💵` icon
15. **`#mechanism` H2 + opener with historical-depth sentence** + `.mechanism-steps` — 5 numbered steps. Each step has a bold lead phrase + body + `<em>` italicized punchline tell
16. **`#subvariants` H2 + `.subtype-grid`** — 5 cards, each with subtype-region eyebrow, h4 numbered title, mechanic paragraph, *What it feels like:* paragraph, muted *Defense:* / *Most reported in:* footnote
17. **`#where` H2 + `.geo-table-wrap` (overflow-x: auto wrapper)** with `.geo-table` — 8 rows, country-name linked to `/scams/country/<cc>/`, data-bound count bars (8px per documented variant), iconic-pattern cell. Closing italic caption with the % share.
18. **`#cases` H2 + 4× `.case-study`** — Rome, Cairo, Mexico City, Amsterdam (or whichever 4 if the lead scene used a different city). Each card opens with `.case-study-header` (city + tag), `.case-comic` image, full narrative paragraph with USD anchors on all local-currency prices, closing `.city-link` to `/scams/<city>/`.
19. **`#redflags` H2 + `.detail-block.red-flags`** — 9-bullet grid in 2-column layout
20. **`#scripts` `<section class="refusal-scripts">`** — dark indigo card. h3 + intro p + `.script-grid` (8 language cards: Italian, French, Spanish, Arabic, Greek, Turkish, Thai, Universal Fallback). Pronunciation guide on each card.
21. **`#recovery` H2 + opener scene paragraph + tourist-police list + closing data-point paragraph**
22. **Related atlas entries** — h2 + `.related-atlas` grid (6 pills)
23. **Sources** — `.sources-list` block with 8-9 named press + police citations
24. **`.book-strip`** — 3 book cards with cover (flag emoji until R2 covers exist), country-specific stat copy, "Read on Kindle ↗" CTA, $4.99 price
25. **`#faq` H2 + `.faq-section`** — 8 FAQ items with `.faq-q` button + `.faq-a`. Mirrors the JSON-LD FAQPage entries.
26. **`</main>` closes**
27. **`.back-to-top` button** + scroll-listener `<script>`
28. **Footer** — shared partial

## The 12-step build process

### Step 1: Lookup + threshold gate

```bash
# Confirm entry exists in taxonomy
python3 -c "import json; e = [x for x in json.load(open('generators/scam-atlas/data/entries.json'))['entries'] if x.get('slug') == '<SLUG>']; print(e[0] if e else 'NOT FOUND')"
```

If absent → abort. If present, capture: `name`, `entryStyle`, `synonyms`, `subTypes` (broad only), `primaryBookFunnels`, `primaryQueryTarget`, `parentEntry`.

```bash
# Run extract.py to refresh per-entry inventory
python3 generators/scam-atlas/extract.py
python3 -c "import json; inv = json.load(open('generators/scam-atlas/output/entry-inventory.json'))['<SLUG>']; print(inv)"
```

Threshold check:
- `count >= 10` and `countryCount >= 4` → proceed
- Geographic-pinned exception (e.g., `florida-avenue-cambio-hustle`, `ztl-fine-cascade-italy`) → proceed even with 1 country
- Below threshold → flag the user; suggest folding into parent entry

### Step 2: Pick 5 case-study cities + their per-city comics

From `entry-inventory.json` look at `cities[]` for the entry. Pick 5 that span:
- Multiple continents (geographic spread reads as comprehensive)
- Mix of high-volume (Italy, France) + lower-volume but iconic (Cairo, Buenos Aires)
- Cities that already have published `/scams/<city>/` pages (verify with `ls scams/<city>/index.html`)

For each chosen city, find the right comic by grepping the city HTML:

```bash
grep -E 'scam-title|scam-comic.*src=' /Users/bjh/Documents/tabiji/scams/<city>/index.html | head -20
```

The output pairs scam titles with comic URLs in scam-N order. Pick the comic for the topic-relevant scam. **Save these 5 URLs verbatim** — you'll inline them.

**Gotcha:** Not all cities have per-scam comics. Amsterdam, for example, only has `scams-amsterdam-og.jpg`. Fall back to the city's OG image when no per-scam comic exists.

**Gotcha:** Some comic URLs include `?v=2` cache-busters from prior regenerations (e.g., Cairo). Preserve them verbatim.

### Step 3: Pick the lead-scene city

Pick the single strongest narrative city from the 5 (usually one with the richest source-data scam description). This city moves from the case-study section UP into the `.lead-scene` card. Read the source description from `/api/v1/scams/<city>.json` to find the most specific, vivid, time-stamped scene.

### Step 4: Generate the hero comic via comic-pipeline v2

Atlas pages need their own hero comic, distinct from any per-city comic. Use the v2 pipeline with the **default warm-watercolor style** (no country-specific style — atlas pages are by definition cross-country).

```bash
# Run the atlas-specific wrapper that calls synthesize.py + generate.py + uploads to R2
python3 scripts/comic-pipeline/generate_atlas.py <SLUG>
```

The wrapper handles:
1. Reads the atlas entry from `entries.json`
2. Synthesizes a generic-international 4-panel script via Gemini (using one of the 4 cast members per pairing rules — for taxi/transport/airport scams that's **Priya**; fake-police/ATM/currency exchange = **Harry**; restaurant/distraction = **Margie**; nightlife/adventure = **Marcus**)
3. Calls `synthesize.build_full_prompt(country="_default", ...)` to get the warm-watercolor style block
4. Submits to Wavespeed `/edit` endpoint with the default-style pilot anchor (`https://img.tabiji.ai/scam-comics/_default/style-tests/warm-watercolor-storybook.jpg`)
5. Polls until completed (~30-90 sec)
6. Verifies the JPEG (header + ≥120KB)
7. Uploads to R2 at `scams/atlas/<slug>/hero.jpg`
8. Prints the public URL

Reference: `docs/comic-pipeline/styles/_default.md` for the locked default style block, `docs/comic-pipeline/cast.md` for the 4 protagonists.

**Gotcha:** Wavespeed content filter occasionally flags scenes as "potentially sensitive" (~5% rate). On rejection, the wrapper falls back to `/text-to-image` (no style anchor, more permissive filter). If both fail → flag for manual review, do not silently substitute.

**Gotcha:** First fetch after upload sometimes 404s for ~60 seconds due to Cloudflare negative-cache. Wait or hit with `?v=1` query string.

### Step 5: Compose the prose (editorial-only — no Claude API recategorization)

Write each section directly. **Voice rules:**

- **Em dashes:** keep below 5 in main body content. Replace with periods, colons, parentheticals, or semicolons. Em dashes are a tabiji-voice tic but I overuse them — final V0 pilot reduced 51 → 1 in visible body.
- **USD anchors on every local-currency price.** "350 EGP (around $7)" not "350 EGP". "750 pesos (around $44 USD)" not "750 pesos". Required for international readers to gauge severity.
- **"You step out of..." opener** for case-study scenes. Concrete time, place, and luggage state. Compare V0 Buenos Aires vs Rome before/after.
- **One-line italicized punchline per mechanism step** as a `<em>tell</em>` after the body. Examples: *"The first 10 seconds tell you everything."* / *"The math is engineered."* / *"The recovery cost is higher than the loss."*
- **"What it feels like:" sentence** in every sub-variant card. Mechanic + emotional layer. Drives engagement past textbook description.
- **Historical depth where natural.** "The script has been running on tourists in Mediterranean port cities since at least the 1970s." "Buenos Aires arrested 47 cloned-meter drivers in 2024." Concrete dates and numbers, not vague references.
- **No country-specific assumptions in copy.** Atlas pages are global by definition. Italy may show up 15 times in geo data, but the prose should still feel applicable to a reader in Bangkok or Lima.
- **American English** (en-US). No "jewellery" / "centre" / "favour" / "tout". Use "jewelry" / "center" / "favor" / "hustler" or "hustle" instead. Audit before shipping.
- **No emojis except in nav, takeaway icons, and country-flag UI.** Body prose stays clean.
- **Answer-first paragraph rules:** first sentence ≤22 words, AI-citable as a standalone fact, contains the headline number ("65 countries" / "140 variants"). Subsequent sentences are short fragment-style.

### Step 6: Compose the JSON-LD `@graph` (12 entities)

Required entities in this order:
1. **BreadcrumbList** — 4 ListItems
2. **Article** — with these required fields:
   - `headline`, `description`, `url`, `image`, `datePublished`, `dateModified`, `inLanguage: "en"`, `wordCount: <integer>`, `articleSection: "Scam Atlas"`, `keywords: [<7 keywords>]`
   - `author`: Bernard Huang Person object (memory: project_author_byline)
   - `publisher`: tabiji.ai Organization
   - `speakable`: `cssSelector: [".answer-first", ".refusal-scripts", ".faq-a"]`
   - `about: [3 Things]` — broad themes
   - `mentions: [...]` — array containing 5 `{"@id": "<page-url>#place-<city>"}` references for the case-study cities + 8 `Country` entities for the geo-table countries
3. **Place × 5** — one per case-study city, with `@id` matching the mentions reference, `name`, `address`, `url` (links to `/scams/<city>/`)
4. **Book × 3** — one per book CTA card, with `bookFormat: "EBook"`, author, `offers: { price: "4.99", priceCurrency: "USD", url: <amzn.to>, availability: "https://schema.org/InStock" }`
5. **HowTo** — 5-step refusal script (use rideshare app → take only marked taxis → verify base meter → demand receipt → pay with small bills)
6. **FAQPage** — 8 Question/Answer pairs that mirror the visible `.faq-section` in body content

**Gotcha:** Maintain visible-FAQ ↔ JSON-LD-FAQ parity. If you edit one, edit the other in the same commit.

### Step 7: Title + meta description (SERP limits)

- **Title tag**: ≤ **57 chars** (including " | tabiji.ai" suffix). Format: `<Topic>: <hook> (2026 Atlas) | tabiji.ai`. Example: `Taxi Meter Scams in 65 Countries (2026 Atlas) | tabiji.ai` (57 chars).
- **Meta description**: ≤ **155 chars**. Lead with the topic + headline number, then the sub-variants, then the value prop. Example: `Taxi-meter scams documented in 65 countries — cloned meters, long-route detours, counterfeit-bill swaps. The local phrases that shut each one down.` (147 chars).
- **OG title** and **Twitter title** mirror the title tag exactly.

### Step 8: Inline CSS — the editorial-v2 grid override (CRITICAL)

**This is the bug that crashed V0's first preview.** `body.editorial-v2 .content` in `assets/scams.css` line ~1687 sets a `display: grid` 2-column layout (220px sidebar TOC + 1fr main) on desktop ≥900px. Atlas pages don't have a `.toc` element to fill column 1, and use `<section>` elements that don't match the column-2 selector — so all atlas content collapses into the empty 220px sidebar slot.

**Required override** (paste into the page's inline `<style>` block, AFTER the link to `/assets/scams.css`):

```css
@media (min-width: 900px) {
  body.editorial-v2 .content {
    display: block;
    grid-template-columns: none;
    grid-column-gap: 0;
    max-width: 920px;
    padding: 2.5rem 1.5rem;
  }
  body.editorial-v2 .content > * { grid-column: auto; }
}
```

**Future cleanup:** atlas pages should use a new `body class="atlas-v1"` and ship the CSS in `assets/scams.css` proper. For now, inline override is the correct V0 approach.

## Style/voice rules (from V0 iteration audit)

These are the ten editorial dimensions audited on the V0 taxi page. Each has a target and a known anti-pattern.

| Dimension | Target | Anti-pattern |
|---|---|---|
| Em dashes in body | ≤ 5 visible | "Cloned meters running 2-3× the legal tariff — long-route detours that pad distance — counterfeit bill swaps where..." (em dash overuse) |
| First-sentence answer-first | ≤ 22 words, AI-quotable, headline number embedded | "Taxi-meter manipulation is the most-documented transport scam in our archive — recorded in 65 countries across 140 individual variants as of April 2026." (28 words, "as of April 2026" weakens it) |
| Hero h1 | tabiji-voice italic emphasis on a meaningful phrase | "everywhere it runs" (generic) → "country by country" (matches brand tagline) |
| Case-study openers | "You step out of [specific place] at [specific time]..." | "Rome's Fiumicino airport operates posted flat rates..." (descriptive, no scene) |
| USD anchors on local-currency prices | Always | "350 EGP markup" (no anchor) → "350 EGP markup (around $5.50)" |
| Foreign technical terms | Parenthetical explanation on first use | "OV-chipkaart" → "OV-chipkaart (the Dutch transit smartcard you can buy at any station kiosk)" |
| Mechanism step punchlines | Italicized one-line `<em>tell</em>` after each step's body | textbook prose only |
| Sub-variant cards | Mechanic + "What it feels like:" + Defense (3 separate paragraphs) | mechanic + defense only |
| British vs American English | American throughout (jewelry, center, favor, hustle/hustler not tout) | "jewellery" "tout" |
| Section variety | At least 1 dark card (refusal-scripts), 1 grid (sub-variants), 1 table (geo), 5 case-study cards | text-only long-form |

## Comic generation (the v2 pipeline + default style)

Atlas pages get **one** hero comic, generated bespoke per atlas entry, using the **default warm-watercolor storybook style** (no country-specific style — atlas pages are by definition cross-country).

### Why default style for atlas

- Country-specific styles (Hergé France, Studio Ghibli Japan, etc.) only make sense on per-country city pages
- Atlas pages span 65 countries → using any one country's locked style would clash with the geographic spread
- The `_default` warm watercolor reads as "tabiji travel comic" without invoking any specific country's lock
- Locked 2026-04-26 after a 10-candidate bake-off; pilot at `https://img.tabiji.ai/scam-comics/_default/style-tests/warm-watercolor-storybook.jpg`

### What gets generated

A single 4-panel 1:1 image at 2K resolution, uploaded to:
```
R2 path:    scams/atlas/<slug>/hero.jpg
Public URL: https://img.tabiji.ai/scams/atlas/<slug>/hero.jpg
```

### How to generate (the wrapper script)

```bash
python3 scripts/comic-pipeline/generate_atlas.py <SLUG>
```

This is a thin wrapper around `synthesize.synthesize_prompt()` and `generate.submit_job()` from the existing v2 pipeline. The wrapper:

1. Loads `entries.json` and finds the entry by slug
2. Builds a synthetic "scam" dict from the entry's name + primaryQueryTarget + a generic-international location string
3. Calls `synthesize.synthesize_prompt(country="_default", scam=...)` — this:
   - Calls Gemini 2.5 Pro with the cast pairing rules
   - Gemini picks a character (Priya for transit/taxi/airport, Harry for fake-authority/ATM/currency, Margie for restaurant/distraction/charity, Marcus for nightlife/adventure)
   - Gemini writes a 4-panel script: setup → mechanic → realization → lesson
   - All dialogue is English, ≤ 8 words per bubble
4. Assembles the full prompt: `{_default STYLE block}\n\nCHARACTER: {cast paragraph}\n\nSCENE:\n{4 panels}`
5. POSTs to Wavespeed `/edit` endpoint with the default-style pilot URL as the style anchor
6. Polls the result endpoint every 6-7 seconds until `status: completed` (timeout 600s)
7. Downloads the resulting JPEG, verifies header + ≥120KB size threshold
8. If verification fails: retries once via `/text-to-image` (no anchor, more permissive content filter)
9. If still failing: prints `flag for manual review` and exits non-zero
10. On success: PUTs the JPEG to R2 at `scams/atlas/<slug>/hero.jpg` via the Cloudflare API
11. Prints the public R2 URL

### Credentials

Both keys are in macOS keychain — no env files needed:

```bash
WAVESPEED_KEY=$(security find-generic-password -s wavespeed-api-key -w)
R2_TOKEN=$(security find-generic-password -s cloudflare-api-token -w)
GEMINI_KEY=$(security find-generic-password -s gemini-api-key -w)
```

### Gotchas

- **Content filter hit (~5%):** retry via `/text-to-image`. Beach/swim/nightlife scenes most affected.
- **CDN negative-cache after upload:** first fetch sometimes returns 404 for ~60s. Wait or append `?v=1`.
- **Cache-bust on regen:** if regenerating after the first version, append `?v=2` to the `<img src>` to force fresh fetch.
- **Browser User-Agent:** `urllib.request` with default `Python-urllib/3.x` UA gets HTTP 403 from `img.tabiji.ai` (Cloudflare bot filter). Use `User-Agent: Mozilla/5.0` for verification GETs. `curl` is unaffected.
- **`/edit-multi` does NOT support 1:1 aspect ratio.** Use plain `/edit` for atlas hero comics (which are 1:1).

## Known gotchas (the full list)

These all bit me during V0; document them so they don't bite again.

1. **CSS grid bug:** `body.editorial-v2 .content` becomes a 2-column grid on desktop. Atlas pages must override or content collapses to 220px sidebar. **Fix:** the inline override block at the end of inline `<style>`.
2. **Refusal-scripts intro text invisible:** `.body-prose p` selector wins over `.refusal-scripts > p` due to source-order specificity. **Fix:** use `.body-prose .refusal-scripts > p` to bump specificity.
3. **Manual bar widths in geo table look broken on close inspection** when 4 countries tie at 4 variants but bars show 35/35/35/35 (or random). **Fix:** data-bind to `count × 8` pixels.
4. **Section anchors missing for TOC links:** every H2 must have an `id` matching the TOC link target. The TOC and section IDs are easy to forget; lint after writing.
5. **JSON-LD ↔ visible-FAQ drift:** if you edit one, the other goes stale. **Fix:** keep in source-order proximity in the file or write both at once.
6. **Title length silently truncates in SERPs:** Google cuts at ~60 chars. The brand suffix " | tabiji.ai" eats 12 chars; topic title must be ≤48 chars internal.
7. **Meta description length silently truncates:** ~155 chars desktop limit. Last sentence cut off without warning.
8. **OG image 404 hurts social shares:** the placeholder URL `scams/atlas/<slug>/og.jpg` doesn't exist until the comic is generated. Either generate first, or accept that pre-comic pages have no preview image.
9. **`tout` is British-leaning.** Replace with hustler / hustle / scammer / grifter. Source-data tag `tout` in synonyms[] arrays is fine (matching keys); the body prose should not use it.
10. **Em-dash overuse becomes a tic.** Default to periods, colons, parentheticals, semicolons. Em dashes work for parentheticals in the middle of a sentence but not as period-substitutes.
11. **British spellings sneak in:** jewellery/jewelry was the V0 catch. Audit before shipping with the grep at Step 11.
12. **Amazon URL UTM:** `amzn.to` shortlinks don't pass UTM through. `data-utm` attribute is a future hook for the Cloudflare Worker redirect. For now, GA4 click events are the attribution layer.
13. **Comic CDN negative-cache after upload:** wait 60s or use `?v=1`. Test with `curl -I` (NOT `urllib.request` — UA filter).
14. **Wavespeed `edit-multi` doesn't support 1:1.** Use plain `/edit` for atlas (single style anchor + 1:1 aspect) or `/text-to-image` (no anchor, any aspect).
15. **`scripts/build-partials.py` re-runs all shared partials.** If you've edited the page after a partial change, build-partials may not pick up the page until you stage it. Re-run after staging if the nav/footer block on the page is stale.
