# Prompt Template (reference)

> **Note (2026-04-20):** The v1 keyword-classified themed-template approach
> documented below has been **superseded** by the v2 per-scam synthesis
> pipeline. See [prompt-synthesis.md](prompt-synthesis.md) for the current
> production pipeline.
>
> This document is kept as a reference for the underlying 3-block prompt
> format that Nano Banana Pro consumes — that format is unchanged.

Every scam comic prompt has exactly three blocks in this order:

```
{STYLE_BLOCK}

CHARACTER: {cast paragraph}

SCENE:
Panel 1: {what happens}. Speech bubble: "{dialogue}"
Panel 2: {what happens}. Speech bubble: "{dialogue}"
Panel 3: {what happens}. Speech bubble: "{dialogue}"
Panel 4: {what happens}. Speech bubble: "{dialogue}"
```

All three blocks are required. Omitting any one breaks either style lock,
character consistency, or narrative coherence.

## 1. STYLE block

Country-specific. Paste verbatim from [styles/<country>.md](styles/), or use
the `STYLES[country]` constant in
[`scripts/comic-pipeline/styles.py`](../../scripts/comic-pipeline/styles.py).

Do not paraphrase. The exact wording is tuned against the model — "ancient
Greek red-figure pottery storytelling" gives the pottery look, while a
paraphrase like "Greek vase style" does not.

## 2. CHARACTER block

One of the four canonical protagonists from [cast.md](cast.md), or
equivalently `CHARACTERS[<name>]` in
[`scripts/comic-pipeline/cast.py`](../../scripts/comic-pipeline/cast.py).

Paste the full paragraph verbatim — name, age, ethnicity, hair, hat,
clothing, accessories, demeanor. Do not abbreviate to "a silver-haired
woman" — you need the full 60-word block for the model to render the same
Margie across panels.

Character selection is **now done by Gemini** in v2 — see
[prompt-synthesis.md](prompt-synthesis.md). The pairing heuristic that Gemini
is primed with lives in `PAIRING_HINTS` in `cast.py`:

| Character | Best fit |
|---|---|
| Margie | Trust/friendly-stranger scams, restaurant overcharge, fortune tellers, rose sellers, fake charity, counterfeit merchandise — anything that plays on politeness |
| Priya | Transit/taxi/airport/rental, accommodation fraud, QR parking, fake ride-share — anything where a prepared traveler pushes back |
| Harry | Authority-impersonation (fake police, fake inspector), ATM distraction, currency exchange, tailor shops, verbal chat-up cons |
| Marcus | Nightlife, shell game, beach theft, photo-costume, adventure-sport rentals, phone-snatch — anything young + active |

## 3. SCENE block

In **v2**, this block is produced by Gemini from the actual scam's content —
see [prompt-synthesis.md](prompt-synthesis.md). Humans no longer author these
by hand or via keyword templates.

The **format** Gemini is instructed to produce:
- **Panel 1**: setup — protagonist in the environment, scammer approaches
- **Panel 2**: the scam mechanic — the specific bait, switch, or distraction
- **Panel 3**: realization or pushback — protagonist notices or refuses
- **Panel 4**: aftermath / lesson — Tourist Police, correct alternative, or
  memorable one-line advice

**Dialogue rules Gemini enforces:**
- **English only** — even in France/Spain/Germany. Global audience reads English.
- **Under ~8 words per bubble** — longer text risks mis-spelling in Nano Banana Pro.
- **One bubble per panel.**
- **Distinctive, not generic** — "Dienstausweis please!" beats "Show ID!";
  "Only official ticket booths!" beats "Be careful!"
- **Panel 4 is the lesson** — gives every comic narrative closure.

## Worked example (auto-generated by v2)

Input scam:
- **Title**: Brandenburger Tor Petition & Bracelet Pickpocket Distraction
- **Location**: Brandenburger Tor plaza, Pariser Platz
- **Mechanic**: charity-worker approaches with petition; while victim signs,
  an accomplice slips a bracelet over their wrist and picks their pocket

Gemini output:
```json
{
  "character": "margie",
  "character_reason": "This scam preys on politeness and a desire to help.",
  "panels": [
    {"scene": "Margie stands smiling before Berlin's Brandenburg Gate. A young woman approaches, holding a clipboard with a sign that reads 'HELP FOR DEAF CHILDREN'.", "dialogue": "A signature for the children?"},
    {"scene": "Margie focuses on signing. As she does, an accomplice's hand slips a bracelet onto her wrist while a third hand lifts the wallet from her purse.", "dialogue": "Of course, I'm happy to help."},
    {"scene": "The petition-holder is gone. The accomplice aggressively points to the bracelet on Margie's arm. Margie looks at her empty, open purse in shock.", "dialogue": "Ten Euros! Now! My wallet!"},
    {"scene": "Margie speaks to a German Polizei officer. In the background, other tourists are being approached by a similar clipboard group.", "dialogue": "The clipboard is just a distraction."}
  ]
}
```

Notice how this is **specific to this scam**: the clipboard is visible, the
bracelet is being slipped on, the Polizei conclusion — none of which appear
in a generic pickpocket template. That specificity is why v2 exists.

## DEPRECATED: v1 themed-template library

Earlier country scale-ups used a keyword classifier that mapped scam titles
to one of ~25 hard-coded 4-panel templates (e.g. `t_gold_ring`, `t_petition`,
`t_taxi`). This was fast but failed on multi-mechanic titles. See
[prompt-synthesis.md](prompt-synthesis.md) for why we moved on. The templated
approach is **no longer recommended for any new country**.

## What NOT to do

- ❌ Don't paraphrase the STYLE block
- ❌ Don't abbreviate the CHARACTER block
- ❌ Don't put multiple protagonists in one comic
- ❌ Don't write dialogue in the country's language
- ❌ Don't skip Panel 4's lesson/aftermath
- ❌ Don't use the v1 keyword classifier — use the v2 synthesizer instead
- ❌ Don't silently fall back to a template when a generation fails — flag it
