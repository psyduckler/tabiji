## 1. Overview

**tabiji.ai** is a free travel itinerary website that generates personalized trip plans for destinations worldwide. As part of our content marketing strategy, we create short-form travel videos (Instagram Reels) and cross-post them to YouTube Shorts to reach a wider audience.

Our YouTube API integration is a **server-side upload tool** that publishes travel videos to **our own YouTube channel**. End users of tabiji.ai never interact with or authenticate through YouTube — the integration is entirely internal.

---

## 2. YouTube API Services Used

| API Service | Scope | Purpose |
|---|---|---|
| YouTube Data API v3 | `youtube.upload` | Upload video files as YouTube Shorts to our channel |

**This is the only YouTube API scope we use.** We do not:
- Read or display any YouTube data on our website
- Access any user's YouTube account or data
- Embed YouTube players or use YouTube's iframe API
- Use YouTube Analytics, Reporting, or any other YouTube API service

## 3. Authentication & Data Flow

### Architecture

```
[tabiji.ai server] → OAuth 2.0 (refresh token) → YouTube Data API v3 → [Our YouTube channel]
```

### Authentication Details

- **Auth method:** OAuth 2.0 with offline refresh token
- **Credentials:** A single OAuth 2.0 Desktop App client (`gen-lang-client-0583273035`)
- **Authenticated accounts:** 1 (our own Google account)
- **Token storage:** OAuth refresh token is stored securely in macOS Keychain on our server — never exposed to end users, never stored in code or version control
- **Token scope:** `https://www.googleapis.com/auth/youtube.upload` (upload only)

### How It Works

1. A travel video is generated by our content pipeline (AI-generated imagery + text overlays via FFmpeg)
2. Our upload script (`youtube-upload.py`) refreshes an OAuth 2.0 access token using the stored refresh token
3. The script uploads the video file to YouTube via the `videos.insert` endpoint with metadata (title, description, tags, category)
4. The video is published as a YouTube Short on our channel
5. No YouTube data is read back, stored, or displayed anywhere

### User-Facing Integration

**There is no user-facing YouTube integration.** Visitors to tabiji.ai:
- Are never asked to sign in with Google
- Never see YouTube embeds, players, or data on our site
- Have no interaction with YouTube API Services through our platform

## 5. Technical Implementation

### Upload Script

- **Language:** Python 3
- **File:** `youtube-upload.py`
- **Dependencies:** Standard library only (no third-party packages)
- **API endpoint:** `https://www.googleapis.com/upload/youtube/v3/videos` (resumable upload)
- **Video metadata:**
  - `snippet.categoryId`: 19 (Travel & Events)
  - `status.privacyStatus`: public
  - `status.selfDeclaredMadeForKids`: false
  - `status.madeForKids`: false

### Usage

```bash
# Upload a video as a YouTube Short
python3 youtube-upload.py upload video.mp4 \
  --title "One Thing You Must Do in Tokyo" \
  --description "Travel tip from tabiji.ai" \
  --tags "travel,tokyo,japan"
```
