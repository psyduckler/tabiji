# Compare Tier C inventory

These compare pages were classified as Tier C holdouts during compare-page standardization. Per Bernard's instruction, they are recorded here and removed from the active compare inventory.

## Why Tier C was deleted for now

Tier C pages were not deleted because the topics are bad. They were deleted because they were the worst fit for the first standardized compare-page system.

Common reasons:
- bespoke sections beyond the locked `tokyo-vs-kyoto` shell
- heavier editorial structure and longer pages
- more travel-logistics nuance like border crossings, transport combinations, or planning complexity
- richer FAQ / schema density that increases migration risk

The decision here is to keep the active compare inventory clean and standardized around the A/B set instead of carrying visibly off-pattern pages through the transition.

## Rebuild plan

These pages should be rebuilt later, not abandoned.

Recommended rebuild sequence:
1. keep the locked compare shell stable across the active A/B inventory
2. document the extra section patterns Tier C needs
3. extend the compare template/generator for those patterns
4. rebuild Tier C pages one by one on the new system
5. re-add them to `compare/index.html`, `api/v1/compare.json`, and sitemap only after they match the standard

Recommended first pages to rebuild manually:
- `paris-vs-rome`
- `barcelona-vs-lisbon`
- `iceland-vs-norway`
- `bali-vs-thailand`
- `greece-vs-italy`
